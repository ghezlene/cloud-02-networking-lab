> Understand how computers communicate, from IP addressing to DNS, routing, and sockets.

## Overview

Networking is the foundation of cloud infrastructure.

Applications, servers, containers, and cloud services all depend on communication between systems.

This project explores the mechanisms behind that communication, starting with basic networking concepts and progressing toward practical troubleshooting and network analysis.

## Learning Objectives

- Understand the OSI and TCP/IP models.
- Understand IP addresses and subnet masks.
- Practise IPv4 subnetting.
- Understand private and public IP addresses.
- Explore MAC addresses and ARP.
- Understand TCP and UDP.
- Understand ports and sockets.
- Explore DNS resolution.
- Understand routing and default gateways.
- Configure and inspect firewall rules.
- Analyse network traffic using Wireshark.
- Build small Python networking utilities.

## Practical Labs

| Lab             | Description                                |
| --------------- | ------------------------------------------ |
| Network Models  | Explore OSI and TCP/IP layers              |
| IP Addressing   | Understand IPv4 addresses and subnet masks |
| Subnetting      | Calculate networks, hosts, and ranges      |
| DNS             | Investigate domain name resolution         |
| TCP and UDP     | Compare transport protocols                |
| Sockets         | Build simple client-server communication   |
| Routing         | Explore routing tables and gateways        |
| Firewalls       | Experiment with network access rules       |
| Packet Analysis | Inspect traffic using Wireshark            |

- DNS lookup utility.
